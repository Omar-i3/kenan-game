# 🎮 لعبة الوحش كنان - Monster Kenan 2D

لعبة 2D حركية وكوميدية ممتعة تعمل على جميع الأجهزة (الهواتف الذكية، الأيبادات، واللابتوبات) وعلى المتصفح مباشرة عبر **GitHub Pages**.

---

## 🌟 الميزات والمواصفات
- 🕹️ **تحكم متكيف ذكي:**
  - **للجوالات والأيبادات:** عصا تحكم باللمس (Virtual Joystick) وزران تفاعليان للاندفاع وفخ الموز.
  - **للابتوبات والكمبيوتر:** دعم مفاتيح الكيبورد (`WASD` للحركة، `Space` للاندفاع، `E` لرمي الموز، `P` للتوقف المؤقت).
- 😱 **تأثير الخسارة المرعب (Jumpscare):** شاشة صدمة فورية بصورة كنان وصوت `w7sh.mp3` عند الاصطدام!
- 🛰️ **رادار كنان (Minimap):** خريطة مصغرة لمتابعة تحركات الوحش كنان.
- 🔦 **وضع الظلام والكشاف (Night Mode عند 40s):** ظلام دامس مع كشاف ضوئي للاعب وعيون حمراء متوهجة لكنان.
- ⚡ **قدرات وفخاخ:** اندفاع خاطف (Dash)، فخ قشرة الموز (Banana Trap)، منصات زيادة السرعة، وأبواب ممر تفاعلية.
- 🏆 **نظام الألقاب الإنجازية الكوميدية:** ("صيد سهل"، "عداء الفزعة"، "أسطورة الهروب"...).

## 🌐 تشغيل اللعبة أونلاين عبر GitHub Pages
1. ارفع ملفات المجلد مباشرة إلى مستودع GitHub (Repository).
2. ادخل على إعدادات المستودع **Settings** -> **Pages**.
3. اختر الفرع `main` ثم احفظ (`Save`) للعب فوراً من أي متصفح!
